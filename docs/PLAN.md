# MERIT-ERP 系統規劃

電腦整機、零件、周邊銷售專用 ERP。

## 公司現況

| 項目 | 現況 |
|---|---|
| 營業型態 | 單一門市（日後可擴充多門市／倉庫） |
| 客戶 | 一般消費者、公司行號 |
| 序號管理 | 多數商品需要（顯卡、主機板、硬碟、整機等） |
| 目前記錄方式 | 紙本 |

## 技術架構

- **網頁系統**：電腦、手機用瀏覽器即可使用，資料即時同步
- **框架**：Next.js（前後端一體）
- **資料庫**：PostgreSQL（透過 Drizzle ORM 存取）
- **部署建議**：Vercel（網站）+ Neon 或 Supabase（資料庫），初期皆有免費方案
- **程式碼**：GitHub 私人倉庫 `likeRAY-ai/MERIT-ERP`

## 模組

1. **基本資料**：商品（分類、品牌、規格、是否需序號）、客戶、供應商、多價格層級（零售／公司）
2. **進貨管理**：進貨單、登記序號、自動計算平均成本、進貨退出
3. **銷售管理**：報價單（成交即為訂單，不另開訂單）、銷貨單、出貨掃描序號、銷貨退回；只使用新台幣，不需幣別、匯率、部門、專案
4. **組裝管理**：組裝單（零件 → 整機）、整機成本、常用配置範本
5. **庫存管理**：即時庫存、低庫存提醒、盤點、庫存異動紀錄
6. **序號追蹤**：每個序號的進貨、銷售、保固、維修歷程
7. **保固與維修（RMA）**：保固查詢、維修單、送修追蹤
8. **帳務**：應收（公司行號月結）、應付、收付款、發票
9. **報表**：銷售、毛利、庫存價值、滯銷商品
10. **租賃**：出租設備（序號追蹤）、租約（月繳、預繳、按天）、押金、自動產生每期租金銷貨單、退租
11. **系統管理**：帳號、角色權限
    - 老闆：全部權限
    - 店員：進貨、銷貨、基本資料；看不到平均成本與毛利
    - 會計：查詢與報表，可看成本，不能開單

## 設計原則

- 模組化：每個功能獨立，共用同一個資料庫與帳號系統，日後新增功能不需重寫
- 所有庫存變動都留下異動紀錄，可追查
- 手機優先：介面在手機上也要好操作
